# Code of conduct

Be respectful, specific, and constructive. Treat contributors' privacy and security as part of
technical quality. Harassment, discrimination, threats, deliberate disclosure of private material,
and deceptive performance or investment claims are not accepted.

Project maintainers may edit or remove harmful content and restrict participation when necessary.
Report conduct concerns privately through the repository owner's GitHub contact channel. Good-faith
technical disagreement is welcome; personal attacks are not.
