# Contributing

Contributions are welcome when they remain strategy-neutral, synthetic, and reproducible.

1. Open an issue describing the engineering problem without private data.
2. Add a failing test that demonstrates one behavior.
3. Implement the smallest change and keep public boundaries typed.
4. Run the full development commands from the README.
5. Confirm every new fixture contains the synthetic-data disclaimer.

Do not submit Expert Advisors, presets, compiled bots, strategy logic, broker/account/server details,
credentials, real reports, market data, personal paths, screenshots, performance claims, or code
whose redistribution rights are unclear.

By contributing, you certify that you have the right to submit the work under Apache-2.0.
