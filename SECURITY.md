# Security policy

## Supported version

Security fixes are currently provided for the latest `0.1.x` revision on `main`.

## Reporting a vulnerability

Use GitHub's private vulnerability reporting feature for this repository. Do not open a public issue
containing a credential, personal path, account identifier, broker/server detail, proprietary
strategy, or real report. Include a minimal synthetic reproduction and the affected version.

Maintainers will acknowledge a report, assess scope, and coordinate remediation and disclosure.
Never test against another person's terminal, account, broker, network, or data without permission.
